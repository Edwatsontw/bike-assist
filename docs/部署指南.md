# bike-assist v3 偵測部署指南（2026-07-20）

把訓練好的 YOLO11n（5 類 pothole/dog/motorcycle/car/bicycle）接進整套系統：
車機到站批次上傳 → 伺服器收圖 → GPU worker 跑偵測 → 依 GPS 標到地圖。

## 整體資料流

```
車機(騎乘存SD:影像+log.csv含GPS)
   │  到站連WiFi
   ▼  POST /api/upload/log + /api/upload/frame/<檔名>
web 容器 (bike-server:8000)  ──存 uploads/ + DB(uploaded_frames)
   │  GET /api/pending
   ▼
inference 容器 (GPU, YOLO11n) ── GET /api/uploads/<檔名> 取圖 → 推論
   │  POST /api/detections
   ▼
web 容器 存 detections(DB) ── /detections 地圖依 GPS 標五類彩色點
```

## 一次性部署步驟

### 1. 放模型權重
把要用的 best.pt 複製到 inference/model/（權重不進 git）：
```powershell
cd C:\Users\Edwatson\Desktop\BIKEEEE\bike-assist-v3
copy ml\runs\safeway_v3_pothole_dog_640-3\weights\best.pt inference\model\best.pt
```

### 2. 啟動伺服器 + GPU worker
需求：主機 NVIDIA 驅動 + nvidia-container-toolkit（Windows 走 Docker Desktop + WSL2 GPU）。
```powershell
cd server
docker compose up -d --build
docker compose logs -f inference      # 看 worker 是否抓到 GPU、載入模型
```
- 先不想弄 GPU？只跑 web：`docker compose up -d --build bike-server`，
  之後再單獨起 inference。
- worker log 應出現「GPU: NVIDIA GeForce RTX 5070」「類別: {0:'pothole',...}」。
  若印「使用 CPU」代表容器沒吃到 GPU（見下方疑難排解）。

### 3. 燒錄韌體
v3 韌體已含站點批次上傳。兩種觸發：
- **手動測試**：瀏覽器開 `http://<車機IP>/upload` → 立刻上傳 SD 的 log.csv+影像
- **自動**：把 `src/main.cpp` 的 `STATION_SSID` 設為歸還站 WiFi 名稱，車機一連上就自動上傳
- **正式部署**（車機在外、伺服器在家）：設 `SERVER_HOST_OVERRIDE` 為家用伺服器
  對外網址（如 Cloudflare Tunnel 網域）；否則預設用「WiFi 閘道:8000」（僅適合
  車機連電腦熱點、閘道就是伺服器的開發測試情境）

## 端到端測試（開發機，車機連電腦熱點）

1. 車機錄一些影像（騎/晃一下讓 SD 有 /dashcam/normal 的圖）
2. 瀏覽器開 `http://<車機IP>/upload` → 回傳 `log=ok normal=N event=M 已上傳`
3. 開 `http://localhost:8000` → 偵測地圖頁：稍等 worker 跑完，地圖出現彩色點
   （坑洞橘/狗紅/機車紫/轎車藍/腳踏車綠），點圖示可看原圖與信心值
4. 上方 chip 可切換各類別顯示/隱藏，數字是各類累計偵測數

## 疑難排解

- **worker 印「使用 CPU」**：容器沒吃到 GPU。確認 `nvidia-smi` 在主機可用、
  Docker Desktop 已開 GPU 支援；`docker compose` 需支援 `deploy.resources.devices`。
  真的弄不定 GPU，可先把 inference 的 DEVICE 設 cpu 跑通流程（慢）。
- **RTX 5070 報 sm_120 not supported**：base 映像的 torch 太舊。改 `inference/Dockerfile.gpu`
  的 FROM 為較新的 cu128 pytorch 映像（檔內有註解範例），重 build。
- **偵測地圖沒點**：多半是上傳的影格沒 GPS（室內無定位 lat/lon 為空）→ 地圖無法標。
  到有 GPS 定位的環境再錄再上傳。
- **worker 一直沒動作**：`docker compose logs inference` 看有沒有連到
  `http://bike-server:8000`；兩容器要在同一 compose 專案（同網路）。
