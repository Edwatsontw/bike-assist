# SafeWay 展場操作 SOP

> 情境：展場現場，**組員筆電**當伺服器（沒有 NVIDIA 顯卡、沒有 Docker），車機與手機都連組員筆電的熱點。

```
組員筆電（Windows 行動熱點 EdwatsonPC，跑 start_server.bat）
 ├─ 系統端網頁 http://localhost:8000（筆電螢幕直接展示）
 ├─ 車機（ESP32）自動連熱點 → 每 5 秒推資料到 192.168.137.1:8000
 └─ 手機連熱點 → APP 看即時畫面、把手機定位傳給車機、代傳倒車緊急回報
```

## 二、展覽當天開場（約 5 分鐘）

1. **組員筆電**接電源、連上展場網路（地圖底圖需要網路）。
2. 開啟**行動熱點**（`EdwatsonPC`）。
3. 雙擊 `server\start_server.bat`。瀏覽器會自動開 `http://localhost:8000`。
4. **車機上電**。約 10–20 秒後，系統端右上角變成綠點「車機上線」。
5. **手機**連 `EdwatsonPC` 熱點 → 開 SafeWay APP，會自動找到車機。
6. 確認 APP「裝置狀態」：
   - 定位來源 = **手機**
   - IMU / 相機 / SD 卡 = **正常**

## 三、展示流程建議

| 展示點 | 怎麼做 | 觀眾會看到 |
|--------|--------|------------|
| 方向燈 | 撥車上的控制桿 | 尾燈左右閃 |
| 即時儀表板 | APP 打開「串流」開關；指著筆電的系統端儀表板 | 鏡頭畫面、速度、姿態、地圖軌跡 |
| 急煞 / 碰撞 | 輕敲或快速晃動車機 | APP 跳出提示；碰撞後警示燈鎖定、APP 上方出現紅色條 →「解除警示」 |
| 倒車緊急回報 | 把車機放倒超過 10 秒 | 系統端「倒車事件」出現橘點；（5 分鐘後升級紅點緊急事故） |
| AI 路況偵測 | 系統端切到「偵測地圖」 | 坑洞 / 流浪狗位置與照片 |
| 騎乘記錄 | APP 右上地圖圖示 → 點一筆記錄 | 影像＋路線同步回放、急煞碰撞標記 |

> 倒車展示完記得在系統端「倒車事件」按「標記已扶正」，避免紅色警示條一直掛著。

## 四、現場疑難排解

| 狀況 | 先檢查 |
|------|--------|
| 系統端一直「等待車機資料」 | 車機有沒有連上熱點（筆電熱點頁看已連線裝置）；防火牆是否已用系統管理員執行過 bat |
| APP 找不到車機 | 手機是否連 `EdwatsonPC`；手機行動數據先關；或「手動輸入 IP」（熱點頁可看到車機 IP） |
| APP 定位來源一直是「GPS 天線」 | 手機定位權限是否允許；在室內精度差於 100 m 時會自動改用 GPS 天線（正常行為） |
| 地圖一片灰 | 筆電沒有對外網路（底圖從 OpenStreetMap 下載）；資料點仍會顯示 |
| bat 視窗閃一下就關 | 在資料夾空白處按 Shift＋右鍵 →「在終端機開啟」，執行 `.\start_server.bat` 看錯誤訊息 |
| 倒車事件沒出現 | 手機 APP 緊急回報是否已開啟、網址是否正確、手機藍牙是否開著 |

## 五、收場

1. 關掉 `start_server.bat` 的視窗（伺服器停止）。
2. 關行動熱點、車機斷電。
3. 展示當天的資料都留在組員筆電的 `server\data\bike_data.db`，需要的話複製回來。

## 六、備案：車機無法使用時（模擬車機）

車機燒錄失敗、硬體故障時，用組員筆電**模擬車機**，照樣展示 APP 與系統端的軟體功能。

1. 雙擊 `server\demo_mode.bat`（第一次請對它按右鍵「以系統管理員身分執行」，開放 80/81 埠防火牆）。
   會開兩個視窗：伺服器、模擬車機。
2. 手機連組員筆電熱點 → APP 按「自動搜尋裝置」，會找到筆電上的模擬車機（`192.168.137.1`）。
   若 port 80 被佔用，模擬車機會改用 8080，APP 改用「手動輸入 IP」填 `192.168.137.1:8080`。
3. 在模擬車機視窗輸入指令（按 Enter）觸發展示：

| 指令 | 效果 |
|------|------|
| `b` | 急煞（APP 跳提示） |
| `c` | 碰撞（警示燈鎖定，APP 出現紅色條，可按「解除警示」） |
| `f` | 倒車通知（系統端「倒車事件」出現橘點） |
| `e` | 緊急事故（系統端出現紅點與紅色警示條） |
| `p` | 暫停 / 繼續移動 |
| `q` | 結束 |

- 模擬內容：花蓮市區一圈的移動軌跡、速度、姿態；鏡頭畫面輪播 `uploads\` 的路況照片。
- **系統端左上角會顯示橘色「模擬資料」標籤**。建議主動向評審說明「目前以模擬器展示軟體功能」，
  不要把模擬資料當成實測結果。
- 方向燈搖桿、尾燈閃爍、BLE 倒車廣播這些**硬體功能無法模擬**。
