  因先前腳本執行中途逾時漏寫 label 的圖片（`pothole_Pothole-460...`、

- 檔名前綴標示來源：`pothole_`（v2 原始）／`roaddamage_`（Road-damage 補強）／
  `dog_`（Stray Animal Detection）
- road-damage 資料集原始 1263 張裡，有 549 張因為濾掉 crack/damage 後沒有
  剩餘框（畫面裡只有裂縫沒有坑洞），正確捨棄不用
- 資料集切分沿用各來源原始 train/valid/test；road-damage／stray-animal 的
  test split 併入我們的 train（額外訓練量），valid 併入我們的 val

## 執行方式
用 Python 腳本比對檔名前綴＋label 內容過濾／重新編號類別，直接在檔案層級
操作（複製圖片＋改寫 label txt 的 class index），未使用 Roboflow 線上合併
功能。過程中因為掛載硬碟 I/O 較慢，分成多次執行、用「目的檔已存在就跳過」
做到可續跑，非一次到位（供之後類似大量檔案操作參考）。
